# Blais-Rioux Edge Detector

Субпиксельное детектирование фронтов оптического растра на ПЗС-линейке методом Blais-Rioux.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Базовый запуск
```bash
python main.py
```

### С параметрами
```bash
python main.py --n-bits 32 --bit-width 8.0 --noise 80 --seed 123
```

### Сохранение изображения
```bash
python main.py --save result.png --no-window
```

## Параметры CLI

### Симуляция ПЗС
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--n-bits` | Количество бит в последовательности | 24 |
| `--bit-width` | Ширина бита в пикселях (априори) | 7.5 |
| `--blur` | Сигма гауссова размытия оптики | 1.5 |
| `--noise` | Сигма шума АЦП (ADU) | 60 |
| `--vignette` | Сила виньетирования [0..1] | 0.25 |
| `--n-pixels` | Количество пикселей ПЗС | 256 |
| `--seed` | Seed для генератора случайных чисел | 7 |

### Обработка Blais-Rioux
| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--filter-order` | Порядок КИХ фильтра (2 или 4) | 4 |
| `--threshold` | Порог \|D1\| в % от максимума | 15 |
| `--min-dist` | Мин. расстояние между фронтами в % от T | 30 |
| `--smoothing` | Сигма сглаживания перед D1 | 0.5 |
| `--minmax-window` | Ширина окна min/max нормировки | 20 |

### Вывод
| Параметр | Описание |
|----------|----------|
| `--save PATH` | Путь для сохранения изображения |
| `--no-window` | Не показывать окно (только консоль) |

## Алгоритм

### Генерация сигнала (ccd_simulator.py)
1. Случайная битовая последовательность
2. Ступенчатый профиль на сверхдискретной сетке
3. Гауссово размытие (PSF оптики)
4. Пикселизация (интегрирование по ячейкам)
5. Виньетирование (косинусное)
6. Квантование АЦП + шум

### Детектирование фронтов (blais_rioux.py)
1. Глобальная нормализация [0, 1]
2. Гауссово сглаживание
3. КИХ фильтр D1: `h[k] = k / Σk²`
4. КИХ фильтр D2 = D1(D1)
5. Поиск нулей D2: `pos = x + A/(A-B)`
6. Фильтрация по |D1| и расстоянию
7. Минимаксная нормировка в ROI
8. Восстановление бит по знаку D1

### Визуализация (visualizer.py)
- 4 панели: raw signal, processed signal, D1, D2
- Разметка фронтов, ROI, порогов
- Детальный вывод в консоль
