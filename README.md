# Blais-Rioux Edge Detector

1. Генерация симуляции сигнала получаемого на пзс-линейке при прохождении через оптический растр энкодера
2. Обработка сырого сигнала при помощи сглаживания, минимакс нормировки и дифференцирующего КИХ-фильтра порядка N = 2 или 4. Получение субпиксельных положений фронтов бит
3. Восстановление исходной битовой последовательности
4. Визуализация результата

Субпиксельное детектирование фронтов оптического растра на ПЗС-линейке методом Blais-Rioux 2 и 4 порядка.

## Установка

```bash
uv venv
source .venv/bin/activate
uv pip install -e .
```

### Базовый запуск
```bash

encoderdecoder --n-bits 32 --bit-width 8.0 --noise 80 --seed 123

### Сохранение изображения

```

## Алгоритм

### Генерация сигнала (ccd_simulator.py)
1. Случайная битовая последовательность
2. Ступенчатый профиль на сетке
3. Гауссово размытие (эффект оптики и дифракции)
4. Пикселизация (интегрирование по ячейкам)
5. Виньетирование (косинус)
6. Квантование АЦП шум

### Детектирование фронтов (blais_rioux.py)
1. Глобальная нормализация [0, 1]
2. Гауссово сглаживание
3. КИХ фильтр D1: `h[k] = k / sum(k^2)`
4. КИХ фильтр D2 = D1(D1)
5. Поиск нулей D2 линейной интерполяцией `pos = x + A/(A-B)`
6. Фильтрация по |D1| и расстоянию
7. Минимаксная нормировка в ROI
8. Восстановление бит по знаку D1

### Визуализация (visualizer.py)
- 4 панели: raw signal, processed signal, D1, D2
- Разметка фронтов, ROI, порогов
- Детальный вывод в консоль
